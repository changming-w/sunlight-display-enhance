# 图像描边增强三种方案对比

---

## 方案一：Sobel 梯度边缘感知描边

> 脚本：`common/algorithm/outline_sobel.py`

### 1.1 方案概述

使用 Sobel 算子计算图像梯度幅值，将所有明暗变化处识别为"边缘"，
然后在边缘处叠加黑色（dark 模式）或白色（glow 模式），形成描边效果。
不区分文字、图标、边框等语义内容，只要有梯度就描。

### 1.2 核心原理

**① 双边滤波降噪**

参数：`d=5, sigmaColor=40, sigmaSpace=5`

双边滤波在平滑噪声的同时保留边缘锐度，避免 JPEG 压缩产生的振铃伪影干扰后续梯度计算。

**② Sobel 梯度计算**

将图像转为灰度后，分别计算水平和垂直方向的 Sobel 梯度（ksize=3），再求梯度幅值 `mag = √(gx² + gy²)`。

梯度幅值反映每个像素处的明暗变化剧烈程度：
- 平坦区域（纯色背景）→ 梯度 ≈ 0
- 文字笔画边缘 → 梯度高
- 照片纹理 → 梯度中等
- JPEG 压缩噪声 → 梯度低

**③ 归一化 + 非线性增强 + 门限**

- **归一化**：`mag / (mag.max() + ε)`，将梯度统一到 [0, 1]
- **非线性增强**：`edge = mag^0.7`（gamma < 1），压缩强边、提亮弱边
- **门限过滤**：`edge[edge < 0.12] = 0`，去掉噪声级别的微弱梯度

**④ 形态学膨胀 + 羽化**

- **膨胀**：`edge_width > 1` 时用椭圆核膨胀边缘图，加粗描边
- **羽化**：高斯模糊（sigma=0.8），将硬切边缘变为柔和渐变过渡

**⑤ 三种描边模式**

| 模式 | 公式 | 效果 |
|---|---|---|
| **dark** | `result = img × (1 - edge)` | edge=0 原图不变，edge=1 纯黑 |
| **glow** | `result = img + edge × (1-img) × 0.8` | edge=0 原图不变，edge=1 接近纯白 |
| **both** | 先 dark 再 glow | 同时有暗边和亮边 |

### 1.3 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `mode` | `"dark"` | 描边模式：dark / glow / both |
| `strength` | `0.7` | 描边强度 0~1，越大描边越深 |
| `edge_width` | `1` | 描边粗细，>1 时触发形态学膨胀 |
| `denoise` | `True` | 是否启用双边滤波降噪 |

### 1.4 处理流程

```
原图 BGR
  ↓ 双边滤波（去压缩噪声，保边缘）
降噪图
  ↓ 灰度 → Sobel → magnitude
梯度幅值图
  ↓ 归一化 → power(0.7) → <0.12 清零
边缘强度图
  ↓ 膨胀（加粗）→ 高斯模糊（羽化）→ × strength
描边 Alpha 图
  ↓ img × (1-edge) 或 img + edge×(1-img)
最终结果图
```

## 方案二：保护性 USM（Unsharp Mask）描边

> 脚本：`common/algorithm/outline_usm.py`

### 2.1 方案概述

本质是保护性 USM，通过对比每个像素与其局部模糊背景的差异，
自动识别文字笔画方向：比周围亮的像素进一步提亮，比周围暗的像素进一步压暗。
在 LAB 亮度通道（L）上操作，等比缩放回 BGR，保持色相不变。

### 2.2 核心原理

**① 双边滤波降噪**

参数：`d=5, sigmaColor=30, sigmaSpace=5`

**② 提取高频信号（USM 核心）**

将图像转到 LAB 色彩空间，取 L（亮度）通道。
对 L 通道做高斯模糊得到"局部背景" blur。
高频信号 `high = L - blur`。

- `high > 0` → 该像素比周围亮（如白字的亮笔画）
- `high < 0` → 该像素比周围暗（如黑字的暗笔画）
- `high ≈ 0` → 平坦区域，无显著变化

关键点：在 L 通道做而不碰颜色，避免后续增强时产生色彩偏移。

**③ 门限过滤**

```
gate = clip((|high| - edge_gate) / edge_gate, 0, 1)
high = high × gate
```

弱高频（压缩噪声、平坦区域）被过滤，只有超过 `edge_gate` 阈值的真实边缘被保留。

**④ 增强叠加**

```
L_new = clip(L + high × strength, 0, 1)
```

将高频信号放大 strength 倍加回原图。亮的更亮、暗的更暗——形成保护性描边效果。

**⑤ 等比回 BGR（保色相）**

```
ratio = L_new / L
out = BGR × ratio
```

用亮度变化的比例等比缩放三个颜色通道，保持色相不变。

### 2.3 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `strength` | `1.2` | 增强强度，越大描边越明显 |
| `radius` | `1.5` | 高斯模糊半径，控制"多宽的笔画"被增强 |
| `edge_gate` | `0.06` | 最小高频幅度阈值，低于此值不增强 |
| `denoise` | `True` | 是否先做双边滤波降噪 |

### 2.4 处理流程

```
原图 BGR
  ↓ 双边滤波（去压缩噪声，保边缘）
降噪图
  ↓ 转 LAB → 取 L 通道
亮度图 L
  ↓ 高斯模糊（radius）→ high = L - blur
高频信号图
  ↓ 门限过滤（edge_gate）→ × strength → L_new
增强后亮度图
  ↓ ratio = L_new / L → BGR × ratio
最终结果图（色相不变）
```

## 方案三：Canny 边缘检测 + 互补色文字描边

> 脚本：`scripts/text_outline.py`

### 3.1 方案概述

三种方案中最复杂的，专门针对文字描边设计。
与其他两种方案最大的区别：**本方案会区分文字和非文字内容，只描文字**。

### 3.2 核心原理

**① Canny 边缘检测**

轻微高斯模糊（3×3）去噪后，使用自适应 Canny 阈值：

```
median = 中位数(灰度图)
low  = median × 0.5
high = median × 1.5
```

自适应阈值能适配不同亮度的图像，避免固定阈值在暗图或亮图上失效。

**② 规则过滤——减掉非文字边缘**

- **规则 1：局部对比度过滤** — 文字笔画边缘两侧亮度差明显，用 7×7 核计算局部对比度，低于 15 的被过滤
- **规则 2：边缘密度过滤** — 图标/照片区域边缘密集，用 21×21 窗口计算边缘面积占比，超过 0.8 的被过滤
- **规则 3：长直线过滤** — Hough 直线检测（minLen=150px），去掉边框、分割线等长直线

**③ 逐像素文字颜色采样**

对每个边缘像素，根据 Sobel 梯度方向判断文字在哪一侧：

1. 计算 Sobel 梯度方向 (nx, ny)
2. 沿梯度方向和逆梯度方向各采样一个像素（offset=3）
3. 比较两个采样点的亮度，选择较暗的一侧（文字笔画）

无论白字黑底还是黑字白底，都能正确采样到文字颜色。

**④ 高反差互补色计算**

- **无彩色（S < 40）**：亮像素 → 纯黑，暗像素 → 纯白
- **有彩色**：色相旋转 180° + 饱和度拉满到 255

白字得到黑边，黑字得到白边，彩色字得到高饱和互补色边。

**⑤ 抗锯齿描边渲染**

```
alpha = 二值 mask → 高斯模糊（sigma=1.2）
result = 原图 × (1-alpha) + 互补色 × alpha
```

高斯模糊做抗锯齿，描边过渡自然。

### 3.3 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `blend_strength` | `0.9` | 描边混合强度 0~1，越大描边越明显 |
| `smooth_sigma` | `1.2` | 描边平滑模糊 sigma，去锯齿 |
| `min_local_contrast` | `15` | 笔画最小局部对比度 |
| `max_edge_density` | `0.8` | 最大边缘密度，超过则视为图标/照片 |

### 3.4 处理流程

```
原图 BGR
  ↓ 灰度化 + 高斯模糊（3×3）
  ↓ Canny 自适应阈值（median ±50%）
全边缘图
  ↓ 局部对比度过滤（7×7 核, min_contrast=15）
  ↓ 边缘密度过滤（21×21 窗口, max_density=0.8）
  ↓ 长直线过滤（Hough, minLen=150）
文字边缘 mask
  ↓ Sobel 梯度方向 → 逐像素采样文字颜色
  ↓ HSV 互补色计算
互补色图
  ↓ Alpha 混合 + 高斯抗锯齿
最终结果图
```

## 三种方案对比

### 核心差异

| 特性 | 方案一：Sobel | 方案二：USM | 方案三：Canny + 互补色 |
|---|---|---|---|
| 边缘检测 | Sobel 梯度 | USM 高频（原图-模糊） | Canny + 规则过滤 |
| 描边方式 | 乘暗/加亮 | 等比缩放亮度 | 互补色 Alpha 混合 |
| 颜色处理 | 不改变色相 | 不改变色相 | 互补色（白→黑，黑→白） |
| 选择性 | 所有边缘 | 所有边缘 | **只描文字边缘** |
| 复杂度 | 低 | 中 | 高 |
| 计算量 | 小 | 中 | 大 |

### 优势对比

| 方案 | 优势 |
|---|---|
| **Sobel** | 实现简单、速度快、适合实时场景 |
| **USM** | 自适应方向（白字提亮/黑字压暗）、LAB 空间色相保真好 |
| **Canny+互补色** | 只描文字、互补色最大反差、阳光下可读性最强 |

### 局限对比

| 方案 | 局限 |
|---|---|
| **Sobel** | 不区分内容（图标/边框全描）、strength<1 时描边为灰色 |
| **USM** | 不区分内容、照片纹理也会被增强、极暗/极亮区域可能溢出 |
| **Canny+互补色** | 计算量最大、规则过滤可能误删文字、Hough 阈值需调优 |

### 适用场景

| 场景 | 推荐方案 |
|---|---|
| 简单快速的 UI 锐化 | 方案一：Sobel |
| 自然锐化、文字清晰度提升 | 方案二：USM |
| 阳光下高反差文字可读性 | 方案三：Canny + 互补色 |
| 只需文字描边、忽略图标 | 方案三：Canny + 互补色 |
| 实时处理、算力有限 | 方案一：Sobel |
