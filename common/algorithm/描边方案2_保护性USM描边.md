# 保护性 USM（Unsharp Mask）描边方案

> 脚本：`common/algorithm/outline_usm.py`

---

## 1. 方案概述

本方案本质是保护性 USM（Unsharp Mask），通过对比每个像素与其局部模糊背景的差异，
自动识别文字笔画方向：比周围亮的像素进一步提亮，比周围暗的像素进一步压暗。
在 LAB 亮度通道（L）上操作，等比缩放回 BGR，保持色相不变。

---

## 2. 核心原理

### 2.1 双边滤波降噪

参数：`d=5, sigmaColor=30, sigmaSpace=5`

与 Sobel 方案类似，先用双边滤波去除压缩噪声，保留真实边缘。

### 2.2 提取高频信号（USM 核心）

将图像转到 LAB 色彩空间，取 L（亮度）通道。
对 L 通道做高斯模糊得到"局部背景" blur。
高频信号 `high = L - blur`。

**high 的含义：**
- `high > 0` → 该像素比周围亮（如白字的亮笔画）
- `high < 0` → 该像素比周围暗（如黑字的暗笔画）
- `high ≈ 0` → 平坦区域，无显著变化

关键点：在 L 通道做而不碰颜色，避免后续增强时产生色彩偏移。

### 2.3 门限过滤

```
gate = clip((|high| - edge_gate) / edge_gate, 0, 1)
high = high × gate
```

弱高频（压缩噪声、平坦区域）被过滤，只有超过 `edge_gate` 阈值的真实边缘被保留。
默认 `edge_gate = 0.06`。

### 2.4 增强叠加

```
L_new = clip(L + high × strength, 0, 1)
```

将高频信号放大 strength 倍加回原图。亮的更亮、暗的更暗——形成保护性描边效果。

### 2.5 等比回 BGR（保色相）

```
ratio = L_new / L
out = BGR × ratio
```

用亮度变化的比例等比缩放三个颜色通道，保持色相不变。
这比直接在 BGR 上做 USM 更不容易产生偏色。

---

## 3. 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `strength` | `1.2` | 增强强度，越大描边越明显 |
| `radius` | `1.5` | 高斯模糊半径，控制"多宽的笔画"被增强 |
| `edge_gate` | `0.06` | 最小高频幅度阈值，低于此值不增强 |
| `denoise` | `True` | 是否先做双边滤波降噪 |

---

## 4. 预设风格对比

| 风格名 | strength | radius | edge_gate | 效果 |
|---|---|---|---|---|
| `soft` | 0.8 | 1.2 | 0.06 | 轻柔，几乎看不出 |
| `mid` | 1.2 | 1.5 | 0.06 | 适中，默认推荐 |
| `strong` | 1.8 | 1.5 | 0.05 | 强烈，文字很锐 |
| `thick` | 1.4 | 2.5 | 0.05 | 粗描边，适合大字 |

---

## 5. 处理流程

```
原图 BGR
  ↓ 双边滤波（去压缩噪声，保边缘）
降噪图
  ↓ 转 LAB → 取 L 通道
亮度图 L
  ↓ 高斯模糊（radius）→ high = L - blur
高频信号图
  ↓ 门限过滤（edge_gate）→ × strength → L_new
增强后亮度图
  ↓ ratio = L_new / L → BGR × ratio
最终结果图（色相不变）
```

---

## 6. 与 Sobel 方案的区别

| 特性 | Sobel 方案 | USM 方案 |
|---|---|---|
| 边缘检测 | Sobel 梯度幅值 | USM 高频（原图 - 模糊） |
| 描边方式 | 直接乘暗/加亮 | 等比例缩放亮度 |
| 色彩保真 | 不改变色相 | 不改变色相（LAB 空间操作） |
| 方向性 | 无方向，所有边缘 | 自适应方向（亮提亮/暗压暗） |
| 参数直觉 | strength 控制浓度 | strength + radius 双控 |

---

## 7. 优势与局限

### 优势
- 自适应方向：白字自动提亮、黑字自动压暗，无需人工指定
- LAB 空间操作，色相保真度高
- 门限过滤有效抑制噪声
- radius 参数可控制增强的"笔画宽度"

### 局限
- 仍不区分文字和非文字边缘
- 对照片纹理区域也会增强，可能出现不自然的高频细节
- ratio 回 BGR 在极暗/极亮区域可能溢出
