# Sobel 梯度边缘感知描边方案

> 脚本：`common/algorithm/outline_sobel.py`

---

## 1. 方案概述

本方案使用 Sobel 算子计算图像梯度幅值，将所有明暗变化处识别为"边缘"，
然后在边缘处叠加黑色（dark 模式）或白色（glow 模式），形成描边效果。
不区分文字、图标、边框等语义内容，只要有梯度就描。

---

## 2. 核心原理

### 2.1 双边滤波降噪

使用双边滤波（Bilateral Filter）预处理图像。双边滤波在平滑噪声的同时保留边缘锐度，
避免 JPEG 压缩产生的振铃伪影干扰后续梯度计算。

参数：`d=5, sigmaColor=40, sigmaSpace=5`

### 2.2 Sobel 梯度计算

将图像转为灰度后，分别计算水平和垂直方向的 Sobel 梯度（ksize=3），再求梯度幅值 `mag = √(gx² + gy²)`。

梯度幅值反映每个像素处的明暗变化剧烈程度：

- 平坦区域（纯色背景）→ 梯度 ≈ 0
- 文字笔画边缘 → 梯度高
- 照片纹理 → 梯度中等
- JPEG 压缩噪声 → 梯度低

### 2.3 归一化 + 非线性增强 + 门限

- **归一化**：`mag / (mag.max() + ε)`，将梯度统一到 [0, 1]
- **非线性增强**：`edge = mag^0.7`（gamma < 1），压缩强边、提亮弱边，让中等强度的文字笔画也能被保留
- **门限过滤**：`edge[edge < 0.12] = 0`，去掉噪声级别的微弱梯度

### 2.4 形态学膨胀 + 羽化

- **膨胀（dilate）**：`edge_width > 1` 时用椭圆核膨胀边缘图，加粗描边
- **羽化（GaussianBlur, sigma=0.8）**：将硬切的二值边缘变为柔和渐变过渡，消除锯齿

### 2.5 三种描边模式

| 模式 | 公式 | 效果 |
|---|---|---|
| **dark** | `result = img × (1 - edge)` | edge=0 原图不变，edge=1 纯黑 |
| **glow** | `result = img + edge × (1-img) × 0.8` | edge=0 原图不变，edge=1 接近纯白 |
| **both** | 先 dark 再 glow | 同时有暗边和亮边 |

---

## 3. 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `mode` | `"dark"` | 描边模式：dark / glow / both |
| `strength` | `0.7` | 描边强度 0~1，越大描边越深 |
| `edge_width` | `1` | 描边粗细，>1 时触发形态学膨胀 |
| `denoise` | `True` | 是否启用双边滤波降噪 |

---

|---|---|---|---|---|

## 5. 处理流程

```
原图 BGR
  ↓ 双边滤波（去压缩噪声，保边缘）
降噪图
  ↓ 灰度 → Sobel → magnitude
梯度幅值图
  ↓ 归一化 → power(0.7) → <0.12 清零
边缘强度图
  ↓ 膨胀（加粗）→ 高斯模糊（羽化）→ × strength
描边 Alpha 图
  ↓ img × (1-edge) 或 img + edge×(1-img)
```

## 6. 优势与局限

### 优势
- 实现简单，计算量小
- 速度快，适合实时场景
- 不改变色相，只改变亮度

### 局限
- 不区分文字和非文字边缘，图标、边框、照片纹理全部被描
- `mag / mag.max()` 归一化在低对比度图像中会放大噪声
- 没有语义过滤机制（无局部对比度、边缘密度、长直线过滤）
- `strength < 1` 时描边为灰色而非纯黑/纯白
