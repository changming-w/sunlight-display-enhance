# Canny 边缘检测 + 互补色文字描边方案

> 脚本：`scripts/text_outline.py`

---

## 1. 方案概述

本方案是三种方案中最复杂的，专门针对文字描边设计。

核心思路：
1. Canny 检测所有边缘
2. 通过规则过滤（局部对比度、边缘密度、长直线）去掉非文字边缘
3. 逐像素采样文字颜色，计算高反差互补色
4. 用互补色在文字边缘上描边，高斯模糊做抗锯齿

与其他两种方案最大的区别：**本方案会区分文字和非文字内容，只描文字**。

---

## 2. 核心原理

### 2.1 Canny 边缘检测

轻微高斯模糊（3×3）去噪后，使用自适应 Canny 阈值：

```
median = 中位数(灰度图)
low  = median × 0.5
high = median × 1.5
```

自适应阈值能适配不同亮度的图像，避免固定阈值在暗图或亮图上失效。

### 2.2 规则过滤——减掉非文字边缘

#### 规则 1：局部对比度过滤

文字笔画边缘两侧亮度差明显。用 7×7 矩形核做膨胀和腐蚀，
计算局部对比度 `= dilated - eroded`。对比度低于 `min_local_contrast`（默认 15）的区域被过滤。

#### 规则 2：边缘密度过滤

图标/照片区域边缘密集，文字区域边缘相对稀疏。
用 21×21 高斯窗口计算局部边缘面积占比，超过 `max_edge_density`（默认 0.8）的区域被过滤。

#### 规则 3：长直线过滤

边框、分割线等长直线不是文字。使用 Hough 直线检测（阈值 100，最小长度 150px），
找到长直线后膨胀 5px 作为掩码，从边缘图中移除。

### 2.3 逐像素文字颜色采样

对每个边缘像素，根据 Sobel 梯度方向判断文字在哪一侧：

1. 计算 Sobel 梯度方向 (nx, ny)
2. 沿梯度方向采样一个像素（offset=3）
3. 沿逆梯度方向采样一个像素
4. 比较两个采样点的亮度，选择较暗的一侧（文字笔画）

这样无论是白字黑底还是黑字白底，都能正确采样到文字颜色。

### 2.4 高反差互补色计算

根据采样到的文字颜色，计算最大反差的互补色：

**无彩色（饱和度 S < 40）：**
- 亮像素（V > 128）→ 纯黑 (0, 0, 0)
- 暗像素（V ≤ 128）→ 纯白 (255, 255, 255)

**有彩色：**
- 色相旋转 180°（OpenCV 中 `H+90 mod 180`）
- 饱和度拉满到 255

这样白字得到黑边，黑字得到白边，彩色字得到高饱和互补色边。

### 2.5 抗锯齿描边渲染

描边使用 Alpha 混合：

1. 二值 alpha → 高斯模糊（sigma=1.2）→ 平滑渐变，消除锯齿
2. 互补色图同样做高斯模糊，保持边缘颜色一致
3. `result = 原图 × (1-alpha) + 互补色 × alpha`

- `blend_strength`（默认 0.9）控制描边的不透明度
- `smooth_sigma`（默认 1.2）控制边缘的柔和程度

---

## 3. 参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `blend_strength` | `0.9` | 描边混合强度 0~1，越大描边越明显 |
| `smooth_sigma` | `1.2` | 描边平滑模糊 sigma，去锯齿 |
| `min_local_contrast` | `15` | 笔画最小局部对比度，低于此值的边缘被过滤 |
| `max_edge_density` | `0.8` | 最大边缘密度，超过则视为图标/照片 |

---

## 4. 处理流程

```
原图 BGR
  ↓ 灰度化 + 高斯模糊（3×3）
  ↓ Canny 自适应阈值（median ±50%）
全边缘图
  ↓ 局部对比度过滤（7×7 核, min_contrast=15）
  ↓ 边缘密度过滤（21×21 窗口, max_density=0.8）
  ↓ 长直线过滤（Hough, minLen=150）
文字边缘 mask
  ↓ Sobel 梯度方向 → 逐像素采样文字颜色
  ↓ HSV 互补色计算
互补色图
  ↓ Alpha 混合 + 高斯抗锯齿
最终结果图
```

## 5. 三种方案对比

| 特性 | Sobel 方案 | USM 方案 | Canny + 互补色方案 |
|---|---|---|---|
| 边缘检测 | Sobel 梯度 | USM 高频 | Canny + 规则过滤 |
| 描边方式 | 乘暗/加亮 | 等比缩放亮度 | 互补色 Alpha 混合 |
| 颜色 | 不改变色相 | 不改变色相 | 互补色（白→黑，黑→白） |
| 选择性 | 所有边缘 | 所有边缘 | **只描文字边缘** |
| 复杂度 | 低 | 中 | 高 |
| 适用场景 | 简单快速锐化 | 自然锐化增强 | 高反差文字描边 |

---

## 6. 优势与局限

### 优势
- 专门针对文字设计，自动过滤图标、边框、照片纹理
- 互补色描边产生最大反差，阳光下可读性最强
- 逐像素颜色采样，适配白字、黑字、彩色字
- 高斯模糊抗锯齿，描边过渡自然

### 局限
- 计算量最大（Canny + Sobel + Hough + 逐像素采样）
- 规则过滤可能误删少量文字边缘
- 对非拉丁文字（中文、日文等）的过滤效果可能不如拉丁文字
- Hough 直线阈值需要针对图像分辨率调优
